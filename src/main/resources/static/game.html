ルール

基本：交互に石を置き、縦・横・斜めに4つ以上並ぶとその石はすべて盤上から除外され、除外数がそのままダメージ量になります（相手が今すぐ受けるわけではなく、一旦「保留」されます）。

相殺：ダメージが保留された直後の相手の手番で、相手も除外を発生させた場合は相殺が発生します。保留量と相手の除外量を比べ、差分だけダメージが発生します（保留側が上回れば保留した側に、相手の除外量が上回れば最初の攻撃者にダメージ）。同数ならダメージ0。相殺判定はこの1回のみで、応答手番で何も起きなければ保留ダメージがそのまま確定します。

バックアタック：除外された跡地には「除外あと」マークが残ります。その場所に石を置くと、除外を伴わない着手なら保留ダメージを1点軽減。除外を伴う反撃（相殺）の場合は自分の除外量に+1（マーク付きの跡地なら+2）が加算されます。相殺・確定のいずれかが起きると、跡地マークはすべて消えます。

ダメージ増加マーク：5巡目（双方が5回ずつ着手し終えた10手目）以降、黒と白それぞれの石の周囲3マス以内にランダムでマークが置かれます。マークの上の石が4つ以上の並びに含まれて除外されると、除外1つにつきダメージ+1されます。以降4巡（8手）ごとに再設置され、設置回数が3の倍数になるたびに1辺あたりの設置数が+1（最大3個）されます。石の上に乗ったマークは、その石が除外されるまで石の上に小さな印として表示され続けます。

勝敗：HPは各6。HPが0以下になった方の負けです。

2人プレイ：この対局IDのリンクを開いた全ブラウザ（スマホ・PC問わず）で同じ盤面を共有します。手番の色を打つ側が、それぞれの端末からマスをクリック／タップしてください。
