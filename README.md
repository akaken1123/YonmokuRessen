# HP制 四目並べ（Javaサーバー版）

もともとブラウザ単体（HTML+JavaScript）で動いていた「HP制四目並べ」を、Spring Boot（Java）製のサーバーと、
それに接続するブラウザ用クライアントという構成に作り直したものです。ゲームのルール・数値・ロジックは
元のバージョンと同一です。

## 構成

- **サーバー**：Java 17 / Spring Boot 3。対局状態（盤面・HP・保留ダメージ・マーク等）をすべてサーバー側で管理し、
  `GameRoom`（`src/main/java/com/yonmoku/game/GameRoom.java`）が元のJavaScript実装のロジックをそのまま移植しています。
- **通信**：着手・リセットはREST API（`/api/games/**`）で行い、結果はSTOMP over WebSocket（`/ws`）で
  その対局IDを開いている全ブラウザにリアルタイム配信されます。これにより、PCのブラウザとスマホのブラウザで
  同じ対局IDのリンクを開けば、同じ盤面を見ながら対戦できます。
- **クライアント**：`src/main/resources/static` 以下の素のHTML/CSS/JavaScript（ライブラリはCDNに頼らずローカル同梱）。
  スマホ・PCどちらの画面幅でも遊べるようにレスポンシブ対応済みです。

## 遊び方

1. アプリを起動する（下記）。
2. ブラウザで `http://localhost:8080/` を開き、「対局を作成する」を押すと専用の対局ID付きリンクが発行されます。
3. 対戦相手に対局ID（またはリンクそのもの）を伝え、相手は自分のスマホ／PCのブラウザでそのリンクを開きます。
4. 手番の色を打つ側が、それぞれの端末から盤面をクリック／タップして対局します（サーバーが手番を管理するため、
   誤った手番でのクリックはエラーになります）。

一人で遊びたい場合は、トップページの「AIと対戦する」から自分の色（先手・後手）を選んで開始できます。
AIは内蔵の簡易AI（`GomokuAi`）で、深い読みは行わず、除外・反撃・バックアタックのシミュレーションと
盤面のヒューリスティック評価だけで着手を選びます。手番が来ると少し間を置いて自動的に着手します。

## 事前準備

- Java 17以上（JDK）がインストールされていること。
  - 確認：`java -version`
  - 未インストールの場合は [Adoptium Temurin](https://adoptium.net/) などからJDK 17以上を入れてください。
- Maven自体のインストールは不要です。リポジトリに同梱されているMaven Wrapper（`mvnw` / `mvnw.cmd`）が、
  初回実行時に必要なMavenを自動でダウンロードして使います。

## ビルド・起動方法

**Windows（コマンドプロンプト / PowerShell）**

```powershell
.\mvnw.cmd clean package
java -jar target\hp-gomoku-1.0.0.jar
```

**macOS / Linux**

```bash
./mvnw clean package
java -jar target/hp-gomoku-1.0.0.jar
```

（Mavenを別途インストール済みで`mvn`コマンドが使える場合は、`mvnw`の代わりに`mvn`でも構いません。）

デフォルトでは `8080` 番ポートで起動します（`PORT` 環境変数で変更可能）。「Port 8080 was already in use」と
表示された場合は、既に起動中の別プロセスが8080番を使っているので、そちらを終了してから再実行してください。

## ルール概要

- 9×9盤・各プレイヤーHP6。
- 縦・横・斜めに4つ以上並ぶとその石は除外され、除外数がダメージとして一旦「保留」されます。
- 保留直後の相手の手番で相手も除外を発生させると相殺判定（差分のみダメージ）。
- 除外あとに石を置くとバックアタック（軽減 or 反撃ボーナス）が発生します。
- 5巡目以降、周囲2マスにランダムでダメージ増加マークが設置され、以降3巡ごとに再設置されます。

詳細なルールはゲーム画面内の「ルール」を参照してください。
