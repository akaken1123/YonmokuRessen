# HP制 四目並べ（Javaサーバー版）

もともとブラウザ単体（HTML+JavaScript）で動いていた「HP制四目並べ」を、Spring Boot（Java）製のサーバーと、
それに接続するブラウザ用クライアントという構成に作り直したものです。ゲームのルール・数値・ロジックは
元のバージョンと同一です。

## 構成

- **サーバー**：Java 17 / Spring Boot 3。対局状態（盤面・HP・保留ダメージ・マーク等）をすべてサーバー側で管理し、
  `GameRoom`（`src/main/java/com/yonmoku/game/GameRoom.java`）が元のJavaScript実装のロジックをそのまま移植しています。
- **通信**：着手・リセットはREST API（`/api/games/**`）で行い、結果はSTOMP over WebSocket（`/ws`）で
  その対局IDを開いている全ブラウザにリアルタイム配信されます。これにより、PCのブラウザとスマホのブラウザで
  同じ対局IDのリンクを開けば、同じ盤面を見ながら対戦できます。
- **クライアント**：`src/main/resources/static` 以下の素のHTML/CSS/JavaScript（ライブラリはCDNに頼らずローカル同梱）。
  スマホ・PCどちらの画面幅でも遊べるようにレスポンシブ対応済みです。
- **効果音**：`js/sfx.js`がWeb Audio APIでレトロ8bit風のSEをその場で合成します（音声ファイル不要）。
  対局画面右上のスピーカーアイコンでオン/オフを切り替えられます（設定はブラウザに保存）。

## 遊び方

1. アプリを起動する（下記）。
2. ブラウザで `http://localhost:8080/` を開き、「対局を作成する」を押すと専用の対局ID付きリンクが発行されます。
3. 対戦相手に対局ID（またはリンクそのもの）を伝え、相手は自分のスマホ／PCのブラウザでそのリンクを開きます。
4. 手番の色を打つ側が、それぞれの端末から盤面をクリック／タップして対局します（サーバーが手番を管理するため、
   誤った手番での着手はエラーになります）。対局画面の「この端末の担当色」で自分の色を指定しておくと、
   自分の手番でない間はその端末では盤面自体が操作できなくなり、誤タップを防げます（同じ端末で黒白を
   交互に打つ場合は「指定しない」のままにします）。

一人で遊びたい場合は、トップページの「AIと対戦する」から自分の色（先手・後手）とAIのレベルを選んで
開始できます。判断基準は主に、(1) 相手が取り得る最善の応手を仮定して被ダメージをできるだけ抑える
（あるいは逆転できる）こと、(2) 相殺・除外の応酬が終わった直後の盤面（残りの石の配置）が自分に有利かを
評価すること、の2点です。単純に「4つ並びを常にブロックする」のではなく、ブロックせず被弾を受け入れて
その後有利になる手も比較したうえで選びます。手番が来ると少し間を置いて自動的に着手します。

- **デフォルトAI**：2手先（自分の着手 → 相手の最善応手）を読む、これまで一番長く動かして調整してきた
  安定版。
- **テストAI**：3手先（自分の着手 → 相手の最善応手 → 自分の追撃）まで読む実験版。読みは深いが、その分
  各段階での候補手の絞り込みが狭くなるため、必ずしもデフォルトAIより強いとは限らない。新しいAIの調整は
  まずこちらに入れ、十分比較できてからデフォルトへ昇格させる想定。
- **テスト2AI**：5手先（自分 → 相手 → 自分 → 相手 → 自分）まで読むさらなる実験版。読みはより深いが、
  各段階での候補手の絞り込みはテストAIよりさらに狭くなるため、これも必ずしもテストAI・デフォルトAIより
  強いとは限らない。
- **テスト3AI**：アルファベータ枝刈り＋反復深化で、1手あたり約1.2秒の持ち時間の許す限りできるだけ深く
  読む実験版。評価関数もHP差の非線形化（追い詰めているほど1点の価値が上がる）・フォーク（あと1手で
  除外を起こせるマスが同時に2つ以上ある状態）の加点・ダメージ増加マーク付きの石が絡むラインの評価を
  加えて強化している。持ち時間内であれば他のレベルより深く読めるが、1手あたりの応答が少し遅くなる。

トップページの「AI対AIを観戦する」では、黒・白それぞれにデフォルトAI／テストAI／テスト2AI／テスト3AIを
割り当てて自動対戦させ、人間の操作なしに観戦できます。どちらが強いか比較するのに使えます。対局画面は
誰が見ても操作不可（観戦専用）になります。

対局中・対局後には、対局画面の「棋譜を見る」から棋譜検討ページ（`review.html`）を開けます。着手ごとの
盤面・HP・保留ダメージを一手ずつ（または手順一覧をクリックして）振り返ることができます。

## 事前準備

- Java 17以上（JDK）がインストールされていること。
  - 確認：`java -version`
  - 未インストールの場合は [Adoptium Temurin](https://adoptium.net/) などからJDK 17以上を入れてください。
- Maven自体のインストールは不要です。リポジトリに同梱されているMaven Wrapper（`mvnw` / `mvnw.cmd`）が、
  初回実行時に必要なMavenを自動でダウンロードして使います。

## ビルド・起動方法

**Windows（コマンドプロンプト / PowerShell）**

```powershell
.\mvnw.cmd clean package
java -jar target\hp-gomoku-1.0.0.jar
```

**macOS / Linux**

```bash
./mvnw clean package
java -jar target/hp-gomoku-1.0.0.jar
```

（Mavenを別途インストール済みで`mvn`コマンドが使える場合は、`mvnw`の代わりに`mvn`でも構いません。）

デフォルトでは `8080` 番ポートで起動します（`PORT` 環境変数で変更可能）。「Port 8080 was already in use」と
表示された場合は、既に起動中の別プロセスが8080番を使っているので、そちらを終了してから再実行してください。

## ルール概要

- 9×9盤・各プレイヤーHP6。
- 縦・横・斜めに4つ以上並ぶとその石は除外され、除外数がダメージとして一旦「保留」されます。
- 保留直後の相手の手番で相手も除外を発生させると相殺判定（差分のみダメージ）。
- 除外あとに石を置くとバックアタック（軽減 or 反撃ボーナス）が発生します。
- 5巡目以降、周囲3マスにランダムでダメージ増加マークが設置され、以降4巡ごとに再設置されます
  （設置回数が3の倍数になるたびに1辺あたりの設置数が+1、最大16個）。

詳細なルールはゲーム画面内の「ルール」を参照してください。
